# 主图文案添加逻辑设计文档

## 一、需求背景

当前 `/suite` 主图(6张)功能生成的图片完全没有文字，需要根据不同产品和平台智能判断：
- 是否需要添加文案
- 文案应该加什么内容
- 文案应该如何呈现

## 二、核心判断逻辑

### 2.1 三层判断机制

```
第一层：文字类型参数
    ↓
第二层：平台规则
    ↓
第三层：产品类型特征
```

### 2.2 判断流程图

```
开始
  ↓
text_type == "无文字"?
  ├─ 是 → 不添加文案（纯净主图）
  └─ 否 → 检查平台规则
            ↓
         平台禁止文案?
           ├─ 是（亚马逊等）→ 不添加文案
           └─ 否 → 检查产品类型
                     ↓
                  产品需要文案?
                    ├─ 是 → 添加智能文案
                    └─ 否 → 可选文案（用户可配置）
```

## 三、平台规则配置

### 3.1 平台分类

| 平台 | 文案策略 | 原因 | 文案风格建议 |

| **独立站** | ⚠️ 可选 | 品牌调性优先，文案可能影响高端感 | 品牌名、简短Slogan |

## 五、文案生成规则

### 5.1 文案内容规则

#### 5.1.1 文案数量
- **主图文案数量**: 1-2个核心卖点
- **每个卖点字数**: 
  - 中文: 2-8字
  - 英文: 2-4词
  - 其他语言: 参考中文规则

#### 5.1.2 文案位置
```
位置选项（按优先级排序）:
1. 顶部居中 - 适合品牌名、产品名
2. 底部居中 - 适合促销信息、价格
3. 左上角 - 适合品牌调性、Logo
4. 右上角 - 适合标签、角标
5. 右侧竖排 - 适合长句文案
6. 环绕商品 - 适合功能标注（慎用）
```

#### 5.1.3 文案风格分类

| 风格类型 | 适用场景 | 特点 | 示例 |
|---------|---------|------|------|
| **功能型** | 数码、家电、工具 | 直接陈述功能卖点 | "快充20W"、"智能控温" |
| **功效型** | 美妆、护肤、个护 | 强调产品功效 | "深层滋养"、"72h保湿" |
| **利益型** | 家居、办公、日用 | 强调用户获得的价值 | "省空间"、"大容量" |
| **促销型** | 电商活动、清仓 | 限时优惠、折扣信息 | "限时特惠"、"买一送一" |
| **品质型** | 高端产品、母婴 | 材质、工艺、认证 | "食品级"、"实木"、"德国工艺" |
| **场景型** | 户外、运动、家居 | 使用场景、适用人群 | "户外防水"、"宝宝适用" |
| **安全型** | 母婴、食品、宠物 | 安全认证、材质保证 | "BPA Free"、"无添加" |

## 六、多张主图文案差异化策略

### 6.1 核心原则

当生成多张主图（6张或10张）时，需要确保：
- **文案内容差异化**：每张主图文案不重复，展示不同卖点
- **文案位置多样化**：避免所有主图文案位置相同
- **文案风格统一化**：字体、配色风格保持一致
- **信息层次分明**：核心主图文案完整，辅助主图文案简化

### 6.2 主图文案分配策略

#### 6.2.1 6张主图文案分配

| 主图位置 | 文案策略 | 文案重点 | 文案位置建议 | 示例（护肤品） |
|---------|---------|---------|-------------|---------------|
| **主图1（封面）** | ✅ 核心卖点文案 | 品牌名 + 核心卖点 | 顶部居中 + 底部居中 | "品牌名 · 深层滋养" |
| **主图2** | ✅ 功效卖点文案 | 核心功效 | 底部居中 | "72h保湿" |
| **主图3** | ✅ 成分卖点文案 | 核心成分 | 右上角 | "烟酰胺精华" |
| **主图4** | ✅ 场景卖点文案 | 使用场景 | 左上角 | "早晚可用" |
| **主图5** | ✅ 人群卖点文案 | 适用人群 | 底部居中 | "敏感肌适用" |

```python
def distribute_text_content(selling_points, output_count, product_category):
    """
    为多张主图分配文案内容
    
    Args:
        selling_points: 产品卖点列表
        output_count: 主图数量（6或10）
        product_category: 产品类别
    
    Returns:
        list: 每张主图的文案配置
    """
    priority_order = SELLING_POINT_PRIORITY.get(product_category, ['功能', '特点', '优势'])
    
    text_distribution = []
    
    for i in range(output_count):
        if i == 0:
            text_config = {
                'position': '封面主图',
                'text_strategy': '核心卖点',
                'text_content': f"品牌名 · {selling_points[0] if selling_points else '核心卖点'}",
                'text_position': 'top_center + bottom_center',
                'need_text': True
            }
        elif i < output_count * 0.7:
            sell_point_idx = i % len(selling_points) if selling_points else 0
            text_config = {
                'position': f'主图{i+1}',
                'text_strategy': '差异化卖点',
                'text_content': selling_points[sell_point_idx] if selling_points else f'卖点{i}',
                'text_position': get_text_position_by_index(i),
                'need_text': True
            }
        else:
            text_config = {
                'position': f'主图{i+1}',
                'text_strategy': '可选文案',
                'text_content': '品牌Logo' if i == output_count - 1 else '',
                'text_position': 'left_top',
                'need_text': False
            }
        
        text_distribution.append(text_config)
    
    return text_distribution


def get_text_position_by_index(index):
    """根据主图序号返回文案位置，确保位置多样化"""
    positions = ['bottom_center', 'right_top', 'left_top', 'bottom_center', 'right_top']
    return positions[index % len(positions)]
```

```python
def should_main_image_have_text(product_category, platform, text_type):
    """
    判断主图是否需要添加文案
    
    Returns:
        tuple: (need_text: bool, text_rules: dict)
    """
    # 第一层：文字类型参数
    if text_type == '无文字':
        return False, {}
    
    # 第二层：平台规则
    platform_rule = PLATFORM_TEXT_RULES.get(platform, {})
    if not platform_rule.get('allow_text', False):
        return False, {}
    
    # 第三层：产品类型
    product_rule = get_product_text_rule(product_category)
    
    return product_rule['need_text'], product_rule


def get_product_text_rule(product_category):
    """根据产品类别获取文案规则"""
    # 检查高优先级类别
    for category, rule in PRODUCT_CATEGORY_TEXT_RULES['high_priority'].items():
        if any(kw in product_category for kw in rule['keywords']):
            return {
                'need_text': True,
                'priority': 'high',
                'text_focus': rule['text_focus'],
                'max_text_length': rule['max_text_length']
            }
    
    # 检查中优先级类别
    for category, rule in PRODUCT_CATEGORY_TEXT_RULES['medium_priority'].items():
        if any(kw in product_category for kw in rule['keywords']):
            return {
                'need_text': True,
                'priority': 'medium',
                'text_focus': rule['text_focus'],
                'max_text_length': rule['max_text_length']
            }
    
    # 检查低优先级类别
    for category, rule in PRODUCT_CATEGORY_TEXT_RULES['low_priority'].items():
        if any(kw in product_category for kw in rule['keywords']):
            return {
                'need_text': True,
                'priority': 'low',
                'text_focus': rule['text_focus'],
                'max_text_length': rule['max_text_length']
            }
    
    # 检查不建议文案的类别
    for category, rule in PRODUCT_CATEGORY_TEXT_RULES['no_text'].items():
        if any(kw in product_category for kw in rule['keywords']):
            return {
                'need_text': False,
                'priority': 'none',
                'reason': rule['reason']
            }
    
    # 默认：可选文案
    return {
        'need_text': True,
        'priority': 'low',
        'text_focus': ['功能', '特点'],
        'max_text_length': 6
    }
```

- 文案必须清晰可辨，禁止乱码、模糊、变形
- 文案配色必须与商品主色调呼应，禁止刺眼高饱和色
