# 主图文案添加逻辑设计文档

## 一、需求背景

当前 `/suite` 主图(6张)功能生成的图片完全没有文字，需要根据不同产品和平台智能判断：
- 是否需要添加文案
- 文案应该加什么内容
- 文案应该如何呈现

## 二、核心判断逻辑

### 2.1 三层判断机制

```
第一层：文字类型参数
    ↓
第二层：平台规则
    ↓
第三层：产品类型特征
```

### 2.2 判断流程图

```
开始
  ↓
text_type == "无文字"?
  ├─ 是 → 不添加文案（纯净主图）
  └─ 否 → 检查平台规则
            ↓
         平台禁止文案?
           ├─ 是（亚马逊等）→ 不添加文案
           └─ 否 → 检查产品类型
                     ↓
                  产品需要文案?
                    ├─ 是 → 添加智能文案
                    └─ 否 → 可选文案（用户可配置）
```

## 五、文案生成规则

### 5.1 文案内容规则

#### 5.1.1 文案数量
- **主图文案数量**: 1-2个核心卖点
- **每个卖点字数**: 
  - 中文: 2-8字
  - 英文: 2-4词
  - 其他语言: 参考中文规则

#### 5.1.2 文案位置
```
位置选项（按优先级排序）:
1. 顶部居中 - 适合品牌名、产品名
2. 底部居中 - 适合促销信息、价格
3. 左上角 - 适合品牌调性、Logo
4. 右上角 - 适合标签、角标
5. 右侧竖排 - 适合长句文案
6. 环绕商品 - 适合功能标注（慎用）
```

#### 5.1.3 文案风格分类

| 风格类型 | 适用场景 | 特点 | 示例 |
|---------|---------|------|------|
| **功能型** | 数码、家电、工具 | 直接陈述功能卖点 | "快充20W"、"智能控温" |
| **功效型** | 美妆、护肤、个护 | 强调产品功效 | "深层滋养"、"72h保湿" |
| **利益型** | 家居、办公、日用 | 强调用户获得的价值 | "省空间"、"大容量" |
| **促销型** | 电商活动、清仓 | 限时优惠、折扣信息 | "限时特惠"、"买一送一" |
| **品质型** | 高端产品、母婴 | 材质、工艺、认证 | "食品级"、"实木"、"德国工艺" |
| **场景型** | 户外、运动、家居 | 使用场景、适用人群 | "户外防水"、"宝宝适用" |
| **安全型** | 母婴、食品、宠物 | 安全认证、材质保证 | "BPA Free"、"无添加" |

#### 修改点2: 新增函数

```python
def should_main_image_have_text(product_category, platform, text_type):
    """
    判断主图是否需要添加文案
    
    Returns:
        tuple: (need_text: bool, text_rules: dict)
    """
    # 第一层：文字类型参数
    if text_type == '无文字':
        return False, {}
    
    # 第二层：平台规则
    platform_rule = PLATFORM_TEXT_RULES.get(platform, {})
    if not platform_rule.get('allow_text', False):
        return False, {}
    
    # 第三层：产品类型
    product_rule = get_product_text_rule(product_category)
    
    return product_rule['need_text'], product_rule


def get_product_text_rule(product_category):
    """根据产品类别获取文案规则"""
    # 检查高优先级类别
    for category, rule in PRODUCT_CATEGORY_TEXT_RULES['high_priority'].items():
        if any(kw in product_category for kw in rule['keywords']):
            return {
                'need_text': True,
                'priority': 'high',
                'text_focus': rule['text_focus'],
                'max_text_length': rule['max_text_length']
            }
    
    # 检查中优先级类别
    for category, rule in PRODUCT_CATEGORY_TEXT_RULES['medium_priority'].items():
        if any(kw in product_category for kw in rule['keywords']):
            return {
                'need_text': True,
                'priority': 'medium',
                'text_focus': rule['text_focus'],
                'max_text_length': rule['max_text_length']
            }
    
    # 检查低优先级类别
    for category, rule in PRODUCT_CATEGORY_TEXT_RULES['low_priority'].items():
        if any(kw in product_category for kw in rule['keywords']):
            return {
                'need_text': True,
                'priority': 'low',
                'text_focus': rule['text_focus'],
                'max_text_length': rule['max_text_length']
            }
    
    # 检查不建议文案的类别
    for category, rule in PRODUCT_CATEGORY_TEXT_RULES['no_text'].items():
        if any(kw in product_category for kw in rule['keywords']):
            return {
                'need_text': False,
                'priority': 'none',
                'reason': rule['reason']
            }
    
    # 默认：可选文案
    return {
        'need_text': True,
        'priority': 'low',
        'text_focus': ['功能', '特点'],
        'max_text_length': 6
    }


def build_main_image_text_prompt(product_json, platform, text_type, country, text_rules):
    """生成主图文案提示"""
    platform_rule = PLATFORM_TEXT_RULES.get(platform, {})
    
    prompt_parts = [
        f"文案数量: 1-2个核心卖点",
        f"文案长度: 中文2-{text_rules['max_text_length']}字，英文2-4词",
        f"文案重点: {', '.join(text_rules['text_focus'])}",
        f"文案风格: {platform_rule.get('style', 'selling_point')}",
        f"文案位置: 顶部或底部，不遮挡商品主体",
        f"配色要求: 与商品主色调呼应，低饱和，清晰易读",
        f"字体要求: 匹配产品风格，简洁大方",
        "",
        "禁止项:",
        "- 虚假宣传、夸大效果",
        "- 遮挡商品主体、模特面部、关键细节",
        "- 过多文字堆砌（超过2行）",
        "- 乱码、模糊、变形、高饱和刺眼配色"
    ]
    
    return '\n'.join(prompt_parts)
```

## 八、注意事项

### 8.1 优先级冲突处理

当平台规则和产品类型规则冲突时：
- **平台规则优先级更高**
- 例如：美妆产品（需要文案）+ 亚马逊（禁止文案）= 不添加文案

### 8.2 文案质量控制

- 文案必须清晰可辨，禁止乱码、模糊、变形
- 文案配色必须与商品主色调呼应，禁止刺眼高饱和色
- 文案位置必须避开商品主体、模特面部、关键细节

### 8.3 用户可配置性

建议在UI层面提供用户配置选项：
- **强制添加文案**：忽略平台规则，强制添加
- **强制不添加文案**：忽略产品类型规则，强制不添加
- **智能判断**：使用系统默认逻辑

### 8.4 后续优化方向

1. **AI智能生成文案**：根据商品图片和卖点，AI自动生成最适合的文案内容
2. **A/B测试**：对比有文案和无文案的主图点击率
3. **多语言支持**：支持更多语言的文案生成
4. **文案模板库**：建立行业文案模板库，提高生成效率
