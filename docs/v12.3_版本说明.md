## 🆕 新增功能

### 智能文案判断系统

#### 三层判断机制
1. **文字类型参数** - 用户明确指定是否需要文字
2. **平台规则** - 根据平台规则判断是否允许文字
3. **产品类型** - 根据产品特征判断是否适合文字

#### 平台规则配置（12个平台）
- **亚马逊** - 禁止文案
- **独立站** - 低优先级，品牌导向
- **淘宝天猫1688** - 高优先级，卖点导向
- **拼多多抖音电商** - 高优先级，促销导向
- **Temu** - 中优先级，英文简洁
- **TikTok Shop** - 低优先级，视觉优先
- **Shopee** - 中优先级，当地语言
- **OZON** - 中优先级，俄语卖点
- **阿里国际站** - 低优先级，专业风格
- **速卖通** - 中优先级，英文卖点
- **SHEIN** - 低优先级，时尚简约
- **京东** - 高优先级，卖点导向

#### 产品类型分类（15个大类）
**高优先级**（强烈建议添加文案）
- 美妆护肤
- 个护清洁
- 食品饮料
- 母婴用品

**中优先级**（建议添加文案）
- 数码配件
- 小家电
- 宠物用品

**低优先级**（可选文案）
- 运动户外
- 家居用品

**不建议**（不添加文案）
- 服饰鞋包
- 珠宝首饰
- 奢侈品
